abntexto-ufc · standalone validator

UFC/ABNT PDF Validator

Analyzes the PDF in the browser. In Web/Lite mode, the file is not sent to a server. The result does not replace official review by the Sistema de Bibliotecas da UFC.

Normative basis

Validation rules are loaded from a single versioned catalog. Newer UFC sources and current ABNT standards take precedence over older references in institutional guides. Normative updates must be audited in the catalog before changing validation results.
