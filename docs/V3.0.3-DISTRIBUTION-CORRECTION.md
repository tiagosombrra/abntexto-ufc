# v3.0.3 distribution correction

## Scope

This corrective line fixes the user-facing distribution contract discovered after publishing GitHub Release v3.0.2.

The intended policy is:

- CTAN archive: no UFC institutional mark asset; the CTAN example remains `coat-of-arms=false`;
- Template bundle: includes `assets/institutional/ufc-coat-of-arms.png`, keeps `coat-of-arms=true`, and embeds a reference PDF generated from that exact source;
- Overleaf bundle: includes the same institutional asset, keeps `coat-of-arms=true`, and embeds the same reference PDF;
- proprietary Microsoft font files remain excluded from every archive.

## v3.0.2 finding

The v3.0.2 repository source correctly kept `template/main.tex` with `coat-of-arms=true`, but `tools/build-public-bundles.py` sanitized Template and Overleaf output by changing that setting to `false` and excluding `assets/institutional/`. The bundle regression tests enforced that incorrect policy.

The v3.0.2 CTAN archive is correct and must remain immutable. The already published GitHub v3.0.2 assets must also remain immutable historical bytes.

## Corrective implementation

The v3.0.3 correction:

1. stops rewriting `template/main.tex` for Template/Overleaf;
2. includes exactly `assets/institutional/ufc-coat-of-arms.png` in both user bundles;
3. builds `abntexto-ufc-reference.pdf` with `coat-of-arms=true` and the bundled PNG;
4. fails if the institutional asset is missing or invalid;
5. keeps CTAN-specific tests fail-closed against institutional mark redistribution;
6. requires Template/Overleaf tests to find exactly the expected institutional asset and `coat-of-arms=true`;
7. keeps proprietary Microsoft fonts excluded everywhere.

## Release discipline

This correction does not mutate tag `v3.0.2`, GitHub Release v3.0.2, or the v3.0.2 CTAN submission. Version-control/release-marker transition to v3.0.3 must occur only as a separate release-control step after the v3.0.2 publication state is reconciled.
