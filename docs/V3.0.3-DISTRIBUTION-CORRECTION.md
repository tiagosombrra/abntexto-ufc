## Scope

v3.0.3 corrects the user-facing distribution defect discovered after GitHub Release v3.0.2 and is now in final repository-audit/candidate-preparation state.

The supported distribution policy is:

- CTAN archive: no UFC institutional mark asset; CTAN example uses `coat-of-arms=false`;
- Template bundle: includes `assets/institutional/ufc-coat-of-arms.png`, keeps `coat-of-arms=true`, and embeds a reference PDF generated from that exact source;
- Overleaf bundle: includes the same institutional asset, keeps `coat-of-arms=true`, and embeds the same reference PDF;
- proprietary Microsoft font files remain excluded from every archive.

## Immutable v3.0.2 boundary

The v3.0.2 source correctly kept the canonical template configured for the institutional mark, but its Template/Overleaf packaging path sanitized those two user bundles and omitted `assets/institutional/`.

The published v3.0.2 tag, GitHub Release assets, checksums and submitted CTAN archive are immutable historical bytes and must never be rewritten. The CTAN archive was already correct for the CTAN surface.

The frozen v3.0.2 release marker is preserved at:

PR #329 changed the v3.0.3 packaging and regression contract so that:

1. Template/Overleaf no longer rewrite the canonical `coat-of-arms=true` setting;
