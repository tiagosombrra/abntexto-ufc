## Classification policy

- **CURRENT_AUTHORITY** — allowed to describe current 3.0.1 state; must be synchronized before publication.
- **CURRENT_POLICY** — permanent/current engineering or normative policy; release-state prose inside it must not point to superseded control files.
- **RELEASE_EVIDENCE** — immutable/retained evidence for the v3.0.1 correction lots; not a current-state handoff unless explicitly stated.
- **HISTORICAL_EVIDENCE** — preserves an earlier phase/recovery fact; must carry a clear historical/superseded banner and pointer to current authority.
- **RELEASE_FIXTURE** — executable/documentation input, not control-plane authority.

Historical evidence should not be rewritten to fabricate a different past. The fix is to classify it unmistakably and remove it from current authority chains.
