## Distribution boundary discovered for R3

The source-tree canonical PDF uses the configured UFC mark because `template/main.tex` has `coat-of-arms=true`. It must therefore **not** be copied verbatim into public bundles. `tools/build-public-bundles.py` already sanitizes the distributed `main.tex` to `coat-of-arms=false`; R3 must compile the public reference PDF from that exact sanitized source variant and prove its identity by hash. No UFC mark asset or proprietary Microsoft font may be redistributed.
