## Rewrite policy

R1.3 is an additive, bounded rewrite against the frozen R1.2 findings. The seven chapter bodies were proven to survive from the reviewed commented-guide commit up to the R1.3 boundary, so the implementation does not replace the guide with a new fictitious document.

No class runtime, normative rule value, source authority, profile behavior or release threshold is intentionally changed by this lot. The goal is to make the existing canonical TCC a complete user-facing explanation of how major requirements map to project mechanisms and evidence.

## Changed canonical source files

The R1.3 implementation changed `template/main.tex` and chapters 1, 2, 3, 4, 5 and 7. `template/chapters/6-academic-objects.tex` was deliberately retained unchanged because its reviewed visual/object corpus was already strong.

The follow-up correction after Linux #400 changes only `template/chapters/1-introduction.tex`: the subsection heading is changed from a moving argument containing the configuration command to the plain semantic title `Configuração central do documento`. The body continues to explain `\ufcsetup` with `\texttt{\string\ufcsetup}`.

## Teaching vocabulary added

`template/main.tex` retains the existing four authority/source callouts and adds two local documentation-only callouts:

- `\guiamecanismo{...}` — public key, command, environment, file or workflow the user manipulates;
- `\guiavalidacao{...}` — test/evidence route and its boundary.

These commands are local to the reference document and do not change the public class API.

## R1.2 gap closure

R1.3 adds or strengthens: coherent `\ufcsetup` guidance; explicit authority/mechanism/evidence separation; optional-list behavior including populated unified illustrations; consolidated pagination/duplex explanation; literal-font versus fallback and font-embedding guidance; a rendered footnote example; citation variants and `apud`; all seven profiles including `scientific-article`; code/algorithm/equation policy boundaries; complete build workflow; CLI/Deep guidance; bounded Web/Lite guidance; accessibility/manual-review limits; and the final delivery checklist.

The existing material on current ABNT editions/UFC precedence, detailed front matter, long quotations, NBR 6023:2025 references, academic objects, IBGE tables, appendices, annexes, index and PDF/A policy distinction is preserved.
