## Status vocabulary

- `COMPLETE_MAPPED`: the TCC explains the topic and `standards/reference-guide-map.json` links it to current sources/rules.
- `DOCUMENTED_NEEDS_TRACE`: the TCC explains/demonstrates the topic, but the reference-guide trace map does not yet make that relationship explicit.
- `PARTIAL`: useful content exists, but one or more of authority, expected rendering, public API mechanism or validation route is not explicit enough for the canonical teaching contract.
- `MISSING`: the canonical TCC does not yet explain the topic at the level required for the release reference.
- `SEPARATE_PROFILE`: intentionally validated outside the undergraduate TCC body and only needs a clear cross-reference from the TCC.

## Initial R1.2 findings

### High-priority missing content

1. **Font embedding** is not explained as a distinct generated-PDF property.
2. **Accessibility** is not explained at the level of the validator's real capabilities and manual-review boundaries.
3. **CLI/Deep validation** is not presented as a user workflow in the TCC.
4. **Web/Lite validation** is not presented as a user workflow and cannot be finalized until R4 repairs the deploy/module graph and real-PDF E2E.

### High-priority partial content

1. `\ufcsetup` has many public keys in `main.tex`, but the TCC does not yet organize them into a coherent configuration guide.
2. Lists are shown and discussed, but the populated unified illustration-list regression that caused PR #302 should be explicitly represented in the canonical reference coverage.
3. Citation variants (`indirect`, `short direct`, `apud`) are described but not all have equally strong physical examples/evidence links.
4. Code/algorithm support is demonstrated but needs clearer separation between project capabilities and normative requirements.
5. Pagination explanation is distributed across chapters 2 and 4 and should be consolidated to avoid contradictory wording.

### Existing strong areas to preserve

The current TCC already contains substantial reviewer-corrected material that should not be discarded during R1.3, especially:

- normative/institutional/project/example callout separation;
- current ABNT version references;
- detailed front-matter guidance;
- A4/margins/body typography;
- long quotation geometry;
- NBR 6023:2025 reference-list guidance;
- object width/source/note examples;
- IBGE numeric tables;
- appendices/annexes/index;
- PDF/A policy distinction;
- profile and strict-font portability distinctions.

## R1.2 completion rule

This initial matrix starts R1.2 but does not close it. Before R1.3 rewrite begins, the machine-readable trace map must be reconciled with all topics that are promoted from `DOCUMENTED_NEEDS_TRACE` or `PARTIAL` to a release-required teaching guarantee. The final R1.2 state must explicitly list which topics are intentionally outside the undergraduate TCC and why.
