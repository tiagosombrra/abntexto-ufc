### 23/10/2026 — correction after exact-head Linux run

The initial ready-for-review Linux 42-check suite failed specifically in the new Spanish inherited-object PDF fixture: Babel reinterpreted an upstream `~` token in `\legendlabel` as an active shorthand (`\language@active@arg~`). This issue is independent of the four-language catalog parity. A minimal LaTeX/Spanish Babel reproduction confirmed the error and showed that ordinary nonbreaking-space commands do not invoke that shorthand. PR #520 therefore now supplies a **document-language-opt-in-only** equivalent of upstream `\legendlabel`, retaining the inherited dynamic legend identifier, object counter and nonbreaking separators with `\nobreakspace`. Legacy PT users do not receive that override. A subsequent full-head run 39936400166 compiled the five locale objects but detected a legacy appendix-label **test false negative** (PDF text had correctly rendered `apêndice a — appendix-object-legacy`, whereas the assertion compared a lowercase extraction to an uppercase marker); the fixture now uses case-normalized label matching and prints bounded extracted evidence when any check fails. The fresh Codex review identified missing normal/alternative sublegend productive coverage, which is now covered as distinct, non-interleaved real-PDF assertions with stable unhyphenated markers. Full-head regression and clean final review remain required.

## Política de execução econômica com qualidade preservada

1. **Durante iterações**, manter uma única PR material em **draft**. Cada push executa Static Contract: sintaxe, contratos e catálogo i18n; o seletor Linux existente evita a suíte pesada para rascunhos. Um status verde só estático **não autoriza merge**.
2. **Diagnóstico direcionado**: executar `frontmatter` ou os testes específicos de idioma, apêndice e objeto, em vez de todas as suítes, ao corrigir problemas comprovados. Registros manuais/escopados são evidência complementar.
3. **HEAD final de revisão**: marcar a PR como pronta, exigir Linux Integration completa (42 checks, nenhum skip) e plataformas aplicáveis, PDFs reais, novo review sobre o último SHA, threads resolvidas.
4. **Depois do merge**: Linux Integration completa no SHA de `main`, Linux Release com 38 checks, CTAN pkgcheck e artefatos verificáveis; revisão visual dos sete perfis por responsável. Publicação permanece proibida até os gates finais.

**Causas da demora:** inicialização da imagem TeX Live, instalações, múltiplas compilações LaTeX por fixture (a matriz de 28 perfis × 3 passes já representa 84 compilações), 42 checks sequenciais e Web/Lite browser E2E. É possível avaliar cache do ambiente e paralelização de fixtures com medições reais; **não** remover passes ou testes que garantem numeração, `eqbox` e TOC sem prova equivalente.

## Critério explícito

Não declarar 100% de conformidade linguística, zero bugs, PDF/UA ou aprovação UFC. Só elevar uma linha de **PENDING** após testes verificáveis sobre o commit final e, quando aplicável, revisão humana/institucional.
