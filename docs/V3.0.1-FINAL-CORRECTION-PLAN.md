- document/profile setup and `\ufcsetup`;

- cover/title/approval/catalog-card policy;
- dedication/acknowledgments/epigraph;
- resumo/abstract/keywords;
- optional lists and table of contents;
- A4, margins, pagination, font, size, color, spacing, paragraph indent;
- section hierarchy;
- indirect, short direct, long direct and apud citations;
- footnotes;
- references/NBR 6023:2025;
- figures, graphs, frames, numerical tables/IBGE, source/note blocks;
- equations;
- source code and algorithms as project-supported academic objects;
- bibliography resources;
- glossary, appendices, annexes, index and conditional spine guidance;
- PDF/A/deposit guidance;
- accessibility and Web/Lite/CLI validation boundaries;
- supported document profiles and portable/strict-font behavior.

Every topic must distinguish one of: `ABNT_NORMATIVE`, `UFC_INSTITUTIONAL`, `PROJECT_POLICY`, `EXAMPLE_OR_RECOMMENDATION`.

- each major rule explains expected appearance, applicable `abntexto-ufc` mechanism and validation/evidence route;
- references used by the guide resolve from `backmatter/references.bib`.
