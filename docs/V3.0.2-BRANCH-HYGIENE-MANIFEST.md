## Purpose

This manifest separates branch-retention decisions from runtime changes. Branches are not deleted merely because they look old or temporary. Historical squash merges mean ancestry alone is insufficient evidence.

Classification policy:

- **KEEP** — canonical or currently active branch.
- **DELETE-CANDIDATE** — branch is tied to a PR GitHub reports as merged. Its branch ref is no longer required for integration history; the PR and commits remain historical evidence.
- **REVIEW** — no merged PR proves disposal yet. These branches require a second pass using PR status, tree/patch equivalence, unique-file review, tag/release references, and historical-document dependencies.
- A `temporary-name signal` is only a prioritization hint, never deletion proof by itself.

## Safety rule

Do not delete REVIEW branches until the second-pass evidence is complete. Because the repository used squash merges extensively, a branch may appear divergent from `main` even when its effective changes were integrated.
