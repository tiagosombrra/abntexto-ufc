# Summary languages — v3.1.0 opt-in policy

**Scope:** The new helper chooses summary and keyword labels from the content language. It does not translate written content or grant ABNT/UFC compliance. It supplements the existing NBR 14724:2024 and NBR 6028:2021 contracts; institutional and journal rules can further constrain languages and ordering.

## Agreed language policy

| Main language | Two-version sequence generated by the opt-in helper | Optional third |
|---|---|---|
| Portuguese (pt) | RESUMO / Palavras-chave, then ABSTRACT / Keywords | None |
| English (en) | ABSTRACT / Keywords, then RESUMO / Palavras-chave | None |
| Spanish (es) | RESUMEN / Palabras clave, then RESUMO / Palavras-chave | ABSTRACT / Keywords |
| French (fr) | RÉSUMÉ / Mots-clés, then RESUMO / Palavras-chave | ABSTRACT / Keywords |

The helper uses main-language-first order by project decision. **Do not claim NBR 14724:2024 mandates this ordering for every foreign-language submission**. Resolve UFC/program deposit requirements for an individual foreign-language work before submission. Research-project and scientific-article profiles may have their own applicability and journal requirements.

## Supported TeX API

The optional **document-language = pt | en | es | fr** setting selects the primary summary language and, **only when explicitly set**, selects the Babel main language at document start; otherwise an existing preamble `\\selectlanguage{english}` (or another legacy Babel selection) is preserved. The initial policy value for summary helpers is PT, independently from the established nine-heading **labels-language** setting. An explicit `document-language` automatically selects the same general-heading locale unless `labels-language` was explicitly set; thus `document-language=en` alone also selects `Contents`, while `document-language=en,labels-language=pt` intentionally retains `Sumário`. The author must set a matching BCP 47 language separately in the pre-class **DocumentMetadata** declaration; no automatic PDF metadata, official institution/degree text, bibliography, hyphenation policy outside Babel, or content translation is claimed.

Example English thesis:

~~~tex
\DocumentMetadata{lang=en-US,pdfstandard=A-2b,pdfversion=1.7}
\documentclass{abntexto-ufc}
\ufcsetup{
  type=doctoral-thesis,
  document-language=en,
  labels-language=en
  % Add mandatory doctoral-thesis metadata...
}
\begin{document}
\pretextual
\ufcPrintRequiredSummaries{frontmatter/summary-en}{frontmatter/summary-pt}
\textual
% Main manuscript...
\end{document}
~~~

The English input file should contain text in English and
\ufcSummaryKeywordsInLanguage{en}{surface meshes; adaptive refinement.}.
The Portuguese file should contain the translation and
\ufcSummaryKeywordsInLanguage{pt}{malhas de superfície; refinamento adaptativo.}.

For Spanish/French manuscripts, the same two-file helper generates RESUMEN/RÉSUMÉ then RESUMO. An optional third English version can be explicitly added with
\ufcPrintOptionalEnglishSummary{frontmatter/summary-en}; it is rejected when the main language is Portuguese or English to avoid duplicate English versions.

For an explicitly controlled order, \ufcPrintSummaryInLanguage{locale}{file} accepts one of pt/en/es/fr. Repeating a locale using the new API raises a class error. Older \ufcPrintSummary, \ufcPrintAbstract, \ufcSummaryKeywords and \keywords are unchanged for existing PT/EN files; avoid mixing old and new commands for the same page.

For scientific-article, \ufcPrintArticleFrontMatter now labels its primary summary according to the main language. \ufcPrintArticleTranslatedSummary{locale}{text} renders a distinctly labeled supplementary article summary, rejecting the primary language and duplicate new-API versions. The legacy two-argument \ufcPrintArticleForeignElements stays unchanged and can still be used when a venue imposes its own foreign abstract formatting.

## Evidence and boundaries

The frontmatter language test builds eight genuine real-PDF scenarios (four languages × thesis/article) and four fail-closed invalid/duplicate-language cases (including unsupported keyword locales), checking headings, keyword labels, body and optional English versions. It supplements the existing NBR 6028 final-PDF check rather than replacing it.

**Not certified:** the accuracy of author translations, institutional authorization of summary order, arbitrary-text word counts, PDF catalog /Lang, foreign degree/title page wording, PDF/UA, journal policy, or human visual release acceptance. Seven complete profile PDFs remain gated by #507; PDF/UA research by #459; v3.1.0 is UNRELEASED. The 29 normative parent rules and public v3.0.5 assets remain unchanged.
