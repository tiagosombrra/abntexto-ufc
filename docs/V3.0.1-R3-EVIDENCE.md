## Purpose

R3 repairs the public distribution so users receive both the editable canonical TCC source and a complete compiled reference PDF, while preserving the intentionally small CTAN smoke/example as a separate artifact role.

## Fixed decisions

1. `docs/ctan-example.tex` remains the minimal CTAN compile/documentation example. The full pedagogical TCC is not a replacement for it.
2. The full public reference PDF is named `abntexto-ufc-reference.pdf`.
3. That PDF is generated from the same sanitized public `main.tex` and project runtime used by the template/Overleaf bundles. It is never manually edited and is never copied from the R2 source-tree PDF.
4. Public source sanitization keeps `coat-of-arms=false`; UFC mark assets are not redistributed.
5. Proprietary Microsoft fonts are not redistributed. Portable fallback behavior remains the public build route unless a user supplies licensed fonts locally.
6. R3 extends the existing `tools/build-public-bundles.py` / `tools/build-distribution-bundles.py` pipeline. No parallel release generator is introduced.
7. The CTAN archive remains lean: it keeps the existing minimal example and does not include `abntexto-ufc-reference.pdf`.
8. Template and Overleaf embed the same generated public reference bytes. The gate nevertheless rebuilds each extracted bundle independently and verifies local source-to-embedded-PDF identity before also checking cross-bundle equality.

## Implementation

`tools/build-public-bundles.py` now materializes the sanitized public project in a clean temporary directory, injects only the pinned upstream `abntexto.cls` required for the build, exports `SOURCE_DATE_EPOCH`, `FORCE_SOURCE_DATE=1` and `TZ=UTC`, and follows the repository build sequence: pdfLaTeX, conditional Biber, conditional glossary/index processing, then two final pdfLaTeX passes. The final log rejects overfull boxes, unresolved references/citations and unresolved Biber rerun requests. The resulting `main.pdf` is embedded as `abntexto-ufc-reference.pdf` in both public usage bundles.

The editable template ZIP still excludes `abntexto.cls`; the Overleaf ZIP still includes the pinned upstream. The pinned upstream is a release-build input for the template reference generation/rebuild proof, not a newly vendored template dependency.

`tests/integration/distribution-bundles.sh` now fails closed unless:

- all public archives remain safe, deterministic and free from proprietary Microsoft font files and institutional mark assets;
- CTAN retains its exact lean shape and does not contain the full pedagogical reference;
- template and Overleaf each contain exactly one `main.tex` and one `abntexto-ufc-reference.pdf`;
- each distributed `main.tex` contains exactly one `coat-of-arms = false` setup and no enabled mark setup;
- each embedded reference starts as a non-empty PDF;
- both public bundles are extracted and rebuilt under the same deterministic release epoch;
- the SHA-256 of each rebuilt `main.pdf` equals the SHA-256 of its embedded `abntexto-ufc-reference.pdf`;
- template and Overleaf embedded reference PDFs are byte-identical;
- the existing outer `SHA256SUMS` and CTAN monolithic-class invariants remain valid.

The gate records both reference hashes, rebuild identity, cross-bundle equality and public mark state in `artifacts/final-certification/distribution-bundles.json`.

## PR integration scope

R3 adds the first-class PR suite `distribution`, containing only `distribution-bundles`. Changes to either public/distribution builder or to the distribution gate select that suite. Orchestration changes combined with distribution changes retain `distribution` rather than fail-closing to the whole integration matrix. The release candidate markers still dominate and force `complete`.

The `distribution-bundles` runner check is PR-only because `make release-check` already owns the release-mode execution of the same gate. This prevents duplicate distribution execution inside the release runner while preserving the independent Linux Release Check workflow.
