## Purpose

R3 repairs the public distribution so users receive both the editable canonical TCC source and a complete compiled reference PDF, while preserving the intentionally small CTAN smoke/example as a separate artifact role.

## Fixed decisions

1. `docs/ctan-example.tex` remains the minimal CTAN compile/documentation example. The full pedagogical TCC is not a replacement for it.
2. The full public reference PDF is generated from the same sanitized public `main.tex` that is distributed in the template/Overleaf bundles. It is never manually edited and is never copied from the R2 source-tree PDF.
3. Public source sanitization keeps `coat-of-arms=false`; UFC mark assets are not redistributed.
4. Proprietary Microsoft fonts are not redistributed. Portable fallback behavior remains the public build route unless a user supplies licensed fonts locally.
5. R3 extends the existing `tools/build-public-bundles.py` / `tools/build-distribution-bundles.py` pipeline. Do not create a parallel release generator.
6. The CTAN archive remains lean by default: keep the existing minimal example and do not add the full TCC PDF unless a concrete CTAN packaging requirement proves that necessary. GitHub template/Overleaf bundles are the intended full-reference distribution surfaces.

## Required implementation

The bounded implementation must:

- compile the sanitized public template deterministically using the release `SOURCE_DATE_EPOCH` contract;
- include a clearly named complete reference PDF in both editable template and Overleaf bundles together with `main.tex` and its support files;
- ensure the embedded PDF was generated from the exact sanitized source/runtime represented by each bundle;
- extend distribution regression to extract the generated bundles, verify the public `main.tex` has `coat-of-arms=false`, reject institutional mark assets/proprietary font files, rebuild the extracted project and require the rebuilt PDF SHA-256 to equal the embedded reference PDF SHA-256;
- retain and separately compile the minimal CTAN example;
- preserve deterministic ZIP construction and the outer `SHA256SUMS` contract.

Prefer the public filename `abntexto-ufc-reference.pdf` unless the existing bundle/test architecture provides a stronger established name. If the implementation chooses another name, record the decision here and in the machine state.

Cross-bundle byte identity is desirable but must not be asserted blindly: template and Overleaf runtime contents differ because Overleaf carries the pinned upstream class. Each bundle must at minimum prove local source-to-embedded-PDF identity. Require cross-bundle PDF equality only if execution demonstrates that the two supported public runtimes produce identical bytes under the same deterministic inputs.
