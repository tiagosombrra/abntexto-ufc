- `template/main.tex` + five chapters: realistic TCC tutorial;
- `docs/USER-GUIDE.md`: workflow and user-facing normative/institutional guidance;
- `docs/COMMAND-REFERENCE.md`: exhaustive public setup/command/environment reference;
- `standards/reference-guide-map.json`: normative traceability bound to the user guide rather than tutorial prose;
- `tests/`: exhaustive and edge-case regression coverage.
