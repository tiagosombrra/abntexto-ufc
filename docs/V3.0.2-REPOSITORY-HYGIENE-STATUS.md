## Governance findings

Current repository policy is already squash-only:

- merge commits disabled;
- rebase merge disabled;
- squash merge enabled;
- `main` deletion/non-fast-forward blocked;
- linear history required;
- PR required with thread resolution.

Two improvements remain:

1. enable automatic deletion of merged branches;

These are repository-administration changes and must be applied only through a supported admin-capable operation; source commits cannot substitute for repository settings.
