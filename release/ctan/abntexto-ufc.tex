\section{Purpose and status}

\pkg{} is an unofficial, community-maintained LaTeX class for academic works at the Federal University of Ceará (UFC), Brazil. It is built on top of the \upstream{} class and provides UFC-oriented front matter, academic-work profiles, bibliography integration, objects, and related formatting support.

The project must not be described as an official or UFC-homologated template unless the University explicitly grants that status.

\section{Requirements}

The class requires LaTeX2e and \upstream{} 1.1 or newer. TeX Live 2026 is the current development target. Bibliography workflows use \texttt{biblatex}/\texttt{biber}; optional class features may load additional packages when enabled.

The package does not redistribute proprietary Microsoft font files or UFC institutional marks. An authorized institutional asset may be supplied locally by the user.

\section{Installation}

When installed through a TeX distribution, start a document with:

\begin{Verbatim}[frame=single]
\documentclass{abntexto-ufc}
\end{Verbatim}

For manual installation, place \texttt{abntexto-ufc.cls} and the accompanying \texttt{abntexto-ufc/} module directory in a location visible to TeX. Install the external \upstream{} dependency separately.

The canonical upstream package page is \url{https://ctan.org/pkg/abntexto}.

\section{Minimal configuration pattern}

The current v3 runtime keeps the Portuguese public API during the R1 reconstruction. A typical document configures metadata with \texttt{\string\ufcsetup} and then prints the required document elements. The full editable template distributed by the project contains the complete set of fields and examples.

\begin{Verbatim}[frame=single]
\documentclass{abntexto-ufc}

\ufcsetup{
  tipo = tccgraduacao,
  autor = {Nome Sobrenome},
  titulo = {Titulo do trabalho},
  local = {Fortaleza},
  ano = {2026},
  orientador = {Prof. Dr. Nome do Orientador},
  ies = {Universidade Federal do Ceara},
  curso-graduacao = {Nome do Curso}
}

\begin{document}
\pretextual
\imprimircapa
\imprimirfolhaderosto
\imprimirsumario

\textual
\chapter{Introducao}
Texto do trabalho.
\end{document}
\end{Verbatim}

The distribution also contains \texttt{abntexto-ufc-example.tex}, which is used by the release validation as an installation smoke test.

\section{Architecture}

The public class file \texttt{abntexto-ufc.cls} loads the external \upstream{} class and then the project-owned modules under \texttt{abntexto-ufc/}. Those modules separate core behavior, fonts, layout, front matter, academic-work profiles, research projects, objects, bibliography, integrations, standards adaptations, back matter, and the public API.

This modular layout is intentional: the CTAN candidate keeps the class and module directory together and does not vendor \texttt{abntexto.cls}.

\section{Public distribution variants}

The project produces distinct release artifacts for different consumers:

\begin{itemize}
  \item a class/runtime archive;
  \item a CTAN submission candidate;
  \item a flattened editable template archive;
  \item a flattened Overleaf archive containing the pinned upstream \texttt{abntexto.cls} for self-contained import.
\end{itemize}

Only the Overleaf bundle vendors the pinned upstream class. The CTAN candidate keeps \upstream{} as a normal external TeX dependency.
