\subsection{Exemplo de código-fonte}

\legend{codigo}{Função de soma em C++}
\ufcfonte{Elaboração própria.}
\label{cod:soma-v2}
\begin{ufclisting}[here]
int soma(int a, int b) {
    return a + b;
}
\end{ufclisting}

O Código~\ref{cod:soma-v2} demonstra o módulo portátil baseado em \texttt{listings}. Para projetos que necessitem de \texttt{minted}, altere a opção \texttt{codigo} e use o fluxo de compilação correspondente.

\subsection{Exemplo de algoritmo}

\legend{algoritmo}{Busca linear}
\ufcfonte{Elaboração própria.}
\label{alg:busca-v2}
\begin{ufcalgoritmo}[here][1]
  \State $i \gets 1$
  \While{$i \leq n$}
    \If{$A[i] = x$}
      \State \Return $i$
    \EndIf
    \State $i \gets i + 1$
  \EndWhile
  \State \Return $-1$
\end{ufcalgoritmo}

O Algoritmo~\ref{alg:busca-v2} usa \texttt{algpseudocodex}, módulo recomendado para pseudocódigo em documentos novos.
